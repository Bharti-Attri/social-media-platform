# SocialMediaPlatform

 SocialMediaPlatform is my personal project — a social media platform built to share and discover photos easily. It’s designed to help users upload, browse, and engage with photos in a clean, simple interface.

---

## What It Does

- Users can create profiles and log in securely
- Upload photos with captions and tags
- Like and comment on photos
- Follow other users to see their latest uploads
- Explore trending and recent photos
- Mobile-friendly and responsive design

---

## Why I Built This

I wanted to deepen my skills in full-stack web development and experiment with building a social platform from scratch, focusing on user experience and photo management.

---

## Technologies

- Frontend: HTML5, CSS, JavaScript
- Backend: Node.js + Express + Mongoose ODM
- Database: MongoDB 
- Authentication: JWT-based login system
  

---

## How to Run It Locally

1. Clone this repo:

   ```bash
   git clone https://github.com/Bharti-Attri/social-media-platform.git
   cd social-media-platform
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables in .env file.
   ```bash
   PORT=3000
   DATABASE_URL=your_database_connection_string
   JWT_SECRET=your_secret_key
   ```
4. Start the app:
   ```bash
   node server.js
   ```
